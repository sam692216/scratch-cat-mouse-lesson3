# Scratch 貓咪走路到貓抓老鼠｜獅湖國小第 3 堂課

本專案保存 Scratch 遊戲基礎班第三堂課的教學範例、教師參考專案、學生拼裝練習版與互動式學習單。

## 專案內容

- `互動式學習單/`：學生學習單、教學工具列、使用說明與學生拼裝版 `.sb3`。
- `互動式學習單/presentation/`：第三堂課 11 頁互動教學簡報，與學生學習單一同由 GitHub Pages 公開。
- 專案根目錄的三個 `.sb3`：課程分析與教師備課參考。
- `1030貓走路專案升級成遊戲.docx`：課程規劃參考稿。
- `Codex/`：專案需求與交付紀錄。

此儲存庫依課程規劃設為公開，因此教師參考 `.sb3`、Word 參考稿及所有網頁素材皆可由任何人瀏覽與下載。

## 離線開啟

在 Windows 檔案總管雙擊 `互動式學習單/index.html`，用 Edge 或 Chrome 開啟；請保留同層的 `assets/` 與 `downloads/` 資料夾。

## 延伸第四、第五堂

建議每堂課沿用 `scratch-cat-mouse-lessonN` 命名方式，各自建立 GitHub 儲存庫；新增 Pages workflow，將該堂課的學生學習單資料夾發布到網站根目錄，並更新此課程入口或 README 中的課程連結。
