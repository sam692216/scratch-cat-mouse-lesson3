02｜今天的學習路線

先動起來，再加上遊戲規則

點選一站，看看這一段要做什麼。

先玩完成版，再看貓咪的初始設定、走路循環、碰邊反彈和喵聲；接著分隊找積木並拼裝。

55–60 分鐘｜休息與喝水

05｜新積木一：變數

變數像一個會記住數字的小盒子

得分盒記住抓到幾次；時間盒記住比賽過了幾秒。

📦

得分變數

⭐ 得分 0

碰到老鼠 → 得分改變 1

每按一次，分數盒就更新一次。

⏱️

變數還可以記時間

計分板和計時器看起來不一樣，其實都在顯示變數裡的數字。

綠旗開始 → 得分設為 0如果碰到老鼠得分改變 1

06｜新積木二：偵測

遊戲要先「知道發生什麼事」

偵測像感應器：碰到了嗎？按鍵按下了嗎？

🐈🐭
碰到老鼠？得分改變 1播放抓到音效移到隨機位置
按按看，老鼠每次會換一處。

07｜偵測按鍵：兩個人一起玩

方向鍵追，WASD 躲

按下面按鈕，看看舞台座標怎麼改變。

🐈🐭

🐈 貓咪｜方向鍵

綠旗 → 重複無限次如果「上箭頭鍵被按下？」y 改變 10

🐭 老鼠｜W A S D

偵測 W / A / S / D改變 x 或 y等待 0.1 秒，再檢查

小口訣：x 管左右；y 管上下。上方 y 加，下方 y 減。

08｜新積木三：運算

時間到 60 秒了嗎？讓積木幫忙比較

「時間 ≥ 60」是一個比較運算：時間到 60，條件才成立。

示意時間0 秒
還沒到 60 秒
當綠旗被點擊 → 時間設為 0重複直到（時間 ≥ 60）運算：時間 ≥ 60？等待 1 秒 → 時間改變 1時間到 → 播放結束音效 → 停止全部

拖曳滑桿查看比較結果；這是積木概念示意，不會真的等待 60 秒。

09｜120 分鐘課堂節奏

把時間留給孩子動手試

0–10 分｜先玩結果預測玩法、找出角色和規則
10–25 分｜貓咪觀察起始設定、走路、反彈、聲音
25–55 分｜分類拼裝積木分隊、組出主程式
55–60 分｜休息喝水、整理畫面
60–75 分｜得分變數碰到角色就記分
75–90 分｜隨機躲藏老鼠換位置再挑戰
90–110 分｜雙人操作方向鍵、WASD 同場遊戲
110–120 分｜計時與回顧運算比較、分享今天的發現

彈性原則：若時間不夠，先確保「貓咪會走」和「碰到老鼠會得分」，其他作為延伸挑戰。
