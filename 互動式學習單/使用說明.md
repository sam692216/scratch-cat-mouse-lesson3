# Scratch 遊戲任務單｜第三堂課使用說明

## 用途
供獅湖國小三、四年級 Scratch 遊戲基礎班課堂跟做與課後回顧。新概念包含變數、偵測及運算；計時器用運算積木比較時間是否達到 60 秒。學生先在網頁試玩完成版的遊戲效果，再於 Scratch 中完成學生拼裝版；課程由貓咪走路與邊緣反彈，逐步延伸至碰撞得分、老鼠隨機定位、雙人控制和限時比賽。

## 教學工具列
頁面底部提供與第二堂課一致的教學工具列，可使用操作、畫筆、螢光筆、箭頭、方框、圓圈、文字、橡皮擦、放大鏡、聚光燈、縮放、顏色與粗細、復原、清除及說明。上課時可用畫筆標示畫面上的積木或遊戲區域。選「操作」或按 Esc 可回到一般操作；註記會保存在目前瀏覽器的本課頁面，與學習單作答分開。

## 開啟方式
在 Windows 檔案總管中雙擊 `index.html`，以 Edge 或 Chrome 開啟。網頁和遊戲所需圖片、音效均隨資料夾附上，可離線使用。請保留 `assets` 與 `downloads` 資料夾，不要只複製 HTML 單檔。

## 課堂示範與學生練習版
- 網頁最上方的「完成版遊戲體驗」是根據教師完成版 Scratch 專案規則及媒體製作的網頁互動示範，供師生先看成果並試玩；它不是 Scratch 執行器，也不提供完整 `.sb3` 下載。
- 學生用的 `.sb3` 位於 `downloads/學生練習版_貓咪走路積木拼裝.sb3`。專案保留舞台、角色、造型與音效，主程式積木已拆開，綠旗積木沒有串接主程式；學生需自行拖曳拼裝。可從 Scratch Desktop 的「檔案 → 從電腦載入」開啟。
- 教師完成版 `.sb3` 保留在本課專案根目錄，不在學習單資料夾或地端 ZIP 中，也沒有網頁下載連結。部署學習單時請只部署 `互動式學習單` 資料夾。

## 學生操作
- 先按「開始遊戲」體驗：貓咪平常左右自動走，按住方向鍵會面朝該方向持續移動，放開後回到自動走路；老鼠按住 W、A、S、D 會朝該方向移動並轉向，兩個方向鍵可斜向移動，兩個造型交替切換；碰到得分，老鼠移到隨機位置，60 秒結束。
- 依序閱讀五個任務；第五關新增方向鍵操作拆解，示範上／下鍵改變 y、左／右鍵改變 x，並說明偵測按鍵、等待與重複積木的組合。限時比賽區另有計時器積木拆解，說明時間變數歸零、每秒累加、達 60 秒後播放音效並停止程式。題目選錯可再選答案重試。
- 第二關按積木卡片，把它們加入程式排序；按卡片可移除，亦可清空重排。
- 在 Scratch 拼裝學生版後，依網頁的提示逐關加上得分、老鼠移動與雙人操作。
- 姓名、文字填答、回顧選單及任務勾選會保存在目前瀏覽器。多人共用同一台裝置時，下課後按「清除記錄，重新開始」。
- 使用「列印／另存 PDF」可列印或另存紙本版；列印時互動控制項會隱藏。

## 課堂時間
0–10 分試玩完成版；10–25 分觀察並拆解貓咪動作；25–55 分積木分類、拼裝與試走；55–60 分休息；60–75 分得分變數；75–90 分老鼠隨機躲；90–120 分雙人賽與回顧。

## 課次與共用工具
本頁為獅湖國小 Scratch 遊戲基礎班第 3 堂課。教學工具列使用 `assets/teaching-tools.css` 與 `assets/teaching-tools.js`，由第二堂課的教學工具列複製並調整為共用內容區啟動方式；不同課次使用各自的瀏覽器註記資料。

## 內容依據與差異
課程說明依據同層三個 `.sb3` 範例及 `1030貓走路專案升級成遊戲.docx`。貓咪起始設定、反彈與音效對照第一個範例；方向鍵、WASD、得分及 60 秒停止對照第二個範例；計時器正數／倒數概念對照第三個範例。網頁示範使用完成版專案的角色媒體，貓咪方向鍵按住時會沿著按鍵方向行走，老鼠依 WASD 轉向並可斜向移動，兩個造型會交替切換；並以瀏覽器程式重現核心玩法；它不是原始 `.sb3` 的網頁播放器。Word 中其他玩法屬延伸建議，不覆蓋實際 `.sb3` 的積木設定。
